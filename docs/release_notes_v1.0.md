# v1.0: TCS DCF Valuation App

Live: https://quant-project-2.vercel.app

A five-year discounted cash flow model of TCS and four peers with every assumption editable:
scenarios, sensitivity, tornado, Monte Carlo, reverse DCF, peer cross-check, football field,
Excel and PDF downloads, shareable links, Screener upload and a daily data refresh.

Tested with 131 Python tests and 3 end-to-end tests; the Excel export matches the Python engine.
Known limitations are listed in the README. Educational project, not investment advice.
